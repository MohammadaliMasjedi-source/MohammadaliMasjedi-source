# Mo Masjedi

I'm Mo — formally **Mohammad Ali Masjedi**. I develop software, study battery life, play classical guitar and teach. Music, engineering, learning and cultural work keep bringing me back to listening, experimenting and making things with other people.

I work in software development at SincoTec and am completing my master's studies in Informatics at TU Clausthal. My research explores early-cycle battery remaining useful life prediction with Python, PyTorch and sequence models. Earlier work includes software engineering, project management and solutions architecture at Hesabfa.

Neda Aryana and I co-founded **Shiraz Art House (SHAH / خانهٔ هنر شیراز)**; I served as CEO from 2014 to 2020. My teaching experience spans school computing, music history, guitar, music theory and individual tuition.

## Try a project

**When should a flashcard come back?** [Open Leitner Trace](https://github.com/MohammadaliMasjedi-source/leitner-trace), a free English/فارسی scheduling lab. Change one answer and see how it moves every later review date. The downloadable edition runs offline by double-click; developers can reuse the JavaScript scheduler or generate a trace from the command line. [See what's changed](https://github.com/MohammadaliMasjedi-source/MohammadaliMasjedi-source/commits/main/projects/leitner-trace/).

**One Python puzzle, in Persian or English.** These strings both look like «آ»: one is a single character; the other is a letter plus a combining mark. What will Python print when you compare them? [حدست را امتحان کن](https://github.com/MohammadaliMasjedi-source/a-byte-of-python-fa/blob/main/labs/PLAY.md#q2) · [Try it in English](https://github.com/MohammadaliMasjedi-source/a-byte-of-python-fa/blob/main/labs/PLAY.en.md#q2). Pick an answer to reveal why. If a Persian explanation didn't click, tell me which sentence lost you in [the book repo](https://github.com/MohammadaliMasjedi-source/a-byte-of-python-fa/issues).

**Help test Sahar (سحر), an offline learning prototype.** If you're a native Dari editor, pick one line in a draft and suggest how you'd say it to a learner, and why. [Find the reviewer role that fits](https://github.com/MohammadaliMasjedi-source/Sahar/blob/main/contribute/REVIEWER-GATE.md). Prefer software testing? [Try a cold start in airplane mode](https://github.com/MohammadaliMasjedi-source/MohammadaliMasjedi-source/blob/main/qa-testing-portfolio/README.md#try-the-same-method-on-sahar) on your own phone. Both tasks are for adult volunteers; no learner data is needed.

**Can a passing test hide a bug?** Try [the TaskTrail filter detective](qa-testing-portfolio/README.md#play-the-three-query-detective-case). You'll judge three live responses from a local task board, check your reasoning, and leave with a reproducible evidence report. Python only; no account or installation of packages.

Follow this profile for new experiments, or go straight to the change history: [Python puzzles](https://github.com/MohammadaliMasjedi-source/a-byte-of-python-fa/commits/main/labs/) · [Sahar](https://github.com/MohammadaliMasjedi-source/Sahar/commits/main/).
